# Worklog Lite dla Jiry — strona

Strona aplikacji Worklog Lite: opis, pomoc, polityka prywatności (po polsku i angielsku) oraz `app-ads.txt` dla AdMob. GitHub Pages publikuje ją pod adresem https://witkowski01.github.io/WorkLogLite/.

Ta strona powstaje w katalogu `site/` repozytorium aplikacji i trafia tutaj poleceniem `npm run site -- publish` (git subtree). Zmiany wprowadzaj w repozytorium aplikacji, nie tutaj, bo następna publikacja by je nadpisała.

| Adres | Plik |
|---|---|
| `/` | opis i pomoc (polski) |
| `/en/` | opis i pomoc (angielski) |
| `/prywatnosc/` | polityka prywatności (polski) |
| `/en/privacy/` | polityka prywatności (angielski) |
| `/app-ads.txt` | autoryzacja sprzedawców reklam AdMob |
